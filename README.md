# Brussel Danst — Animator

Interactieve animatietool voor het logo van het festival **Brussel Danst**. Het logo danst in 4 verschillende moods:

- **Zwanze** — golvend en speels, typisch Brussels
- **Guinguette** — ritmisch op 90 BPM, licht en vrolijk
- **Bal** — energiek op 124 BPM met harde beats
- **Zinneke** — chaotisch en organisch, vol turbulentie

## Over dit project

Prototype gebouwd door [The Kind Kids](https://thekindkids.com) in samenwerking met de klant. Fase 1 van de animator — de exportfunctie volgt in Fase 3.

## Lokaal openen

Dubbelklik op `index.html` — geen server nodig, werkt direct in de browser.
